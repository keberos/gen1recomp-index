There's no way to rename your character once the game starts — Oak asks
once, at the very beginning, and that's it. This adds a **RENAME** row to
the START menu, right above SAVE, that reopens the exact same letter-grid
naming screen and lets you pick a new name at any point.

**On your Pokemon.** Every Pokemon secretly remembers two things about who
caught it: an invisible trainer ID number, and the on-screen name at the
time it was caught. Renaming only changes the on-screen name going
forward — the ID never changes, so nothing that actually matters for
gameplay (the traded-mon EXP bonus, trade-evolution eligibility) is
affected either way.

The one place the on-screen name itself gates behavior is Yellow's starter
Pikachu: the game recognizes it as "the starter" — for following you
around, Pikachu's Beach, and refusing to evolve with a Thunder Stone — by
matching *both* the ID and the name. Left alone, a rename would silently
break that match for a starter caught before the rename. So this mod also
re-stamps the on-screen name on every Pokemon that's actually yours (by
ID) the moment you rename. A genuinely traded-in Pokemon is left showing
its real original trainer, exactly like a real cartridge.

It doesn't rename the rival, only the player.

Marked experimental: built from static engine analysis, not yet verified
in-game.
