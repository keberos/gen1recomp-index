One button opens the TOWN MAP, instead of START → ITEM → scrolling past the
potions → A. Press **Y** while walking around and the map is there; **B**
puts you straight back where you were standing.

**Why this needs a mod at all.** The rebinding screen under OPTION →
CONTROLS rebinds the eight Game Boy buttons and nothing else — every
physical source in the engine, keyboard and controller alike, is mapped onto
up/down/left/right/A/B/START/SELECT. There is no "open the town map" action
anywhere to bind a button to. So this mod makes one.

**Why Y.** On a standard controller, X and Y are the only genuinely free
buttons: the d-pad, A, B, START and SELECT are Game Boy buttons, and all
four shoulders and triggers already cycle game speed. The SELECT+X and
SELECT+Y display chords still work — a press with SELECT held is passed
through untouched.

**You can move it.** The mod's options let you put the map on Y, X, L3, R3,
L1, R1, L2 or R2, or turn the controller binding off entirely. Choosing a
shoulder or trigger takes that one button away from game speed, but only
that one: L1 and L2 both step speed down and R1 and R2 both step it up, so
binding the map to R2 leaves R1 still cycling. There is a keyboard key too
(M by default), and an escape hatch for controllers the system does not
recognise by name.

**A MAP row in the START menu**, on by default, right where ITEM sits. That
is for touch players and for anyone whose controller has no button to
spare — still fewer presses than the bag route, and it lands on the map
rather than on a list of potions.

**It stays out of the way.** The button only works while you are actually
walking around: not in a battle, not in a menu, not during a cutscene or a
text box, not while a trainer is spotting you. Anywhere else the press goes
to the engine untouched, which is also why the keyboard binding cannot eat
an M you are typing into a nickname. A press the mod does not use is always
handed back, so a shoulder binding still cycles game speed the rest of the
time instead of going dead.

**It respects the item.** By default nothing appears until Blue's sister in
Viridian actually hands you the TOWN MAP — no button, no menu row. Turn
NEED TOWN MAP off in the options if you would rather not wait.

No ROM data or game assets are included. The mod opens the engine's own
TOWN MAP screen, the same one the bag item opens.

Verified in game on the defaults. The non-default button choices, the escape
hatch for unrecognised controllers, and the behaviour before you own the
TOWN MAP have not been separately exercised.

A sibling mod, [Button Shortcuts](https://github.com/keberos/button-shortcuts),
adds one-button BICYCLE, FLY, and battle ball-throw shortcuts the same
way — install either alone, or both together with no overlap.
